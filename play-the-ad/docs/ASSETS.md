# Манифест ассетов

| Категория | Источник | Хранение / лицензия |
|---|---|---|
| Все игровые модели и фигурки | Процедурные составные формы этого проекта | `src/core/models.js`, renderer и модули игр; MIT |
| Пластины с отверстиями и крылья бабочки | Собственная генерация сеток | `src/core/geometry.js`; MIT |
| Материалы, освещение, шейдеры и тени | Собственная реализация проекта | `src/core/render.js`; MIT |
| Уровни, схемы комнат и разрушений | Авторские данные проекта | `src/levels.js`, фабрики данных игр; MIT |
| Звуковые эффекты | Синтез Web Audio, не чужие записи | `src/core/runtime.js`; MIT |
| Иконки | Простые Unicode-символы и встроенный SVG динамика | `index.html`, `app.js`; MIT для собственного кода |
| Текст | Интерфейс и инструкции проекта | Русский по умолчанию |
| Шрифты | Системный стек Inter / Segoe UI / Arial / sans-serif | Шрифтовые файлы не поставляются и не скачиваются |

Внешние текстуры, модели, аудиозаписи и CDN не используются. Названия,
персонажи и оформление известных мобильных игр не копировались: использованы
только общие принципы пяти механик из задания. В runtime нет AI API.

Скриншоты и видеозаписи в переданном полном архиве получены из исполняемой
сборки, а не сгенерированы отдельно в качестве рекламных картинок.
