## Фактическая среда

Node.js 22.16.0 локально; Node.js 22.23.2 / Ubuntu 24.04.5 в GitHub Actions.
Chromium 144.0.7559.96, оконный режим под Xvfb, WebGL 2 через ANGLE SwiftShader.
ПК: viewport 1120×820, игровое поле 829×636. Touch: 390×844, поле 370×674,
DPR 1, настоящие события CDP touchStart/Move/End и нажатия touchscreen.
Это эмуляция сенсорного ввода, **не физический телефон**.

Навигацию file:// и HTTP на loopback блокировала политика браузера среды.
Браузер загружал неизменённую production-страницу через `page.set_content`.
Правила исполнялись с фиксированным шагом 1/60 с; управляемые часы подавали
кадры по 100 мс. Это не ускоренный игровой чит и не измерение FPS.

## Дополнительная регрессия

10 проверок пройдены: native touchCancel прекращает стрельбу; пауза
останавливает время без догоняющего скачка; переход посреди действия
освобождает старую сцену; шесть быстрых нажатий не дублируют болт;
поражение и «Ещё раз» возвращают исходное состояние; mute переживает
смену игры; пять размеров окна 320×700–1120×820 не дают переполнения;
50 переключений удерживают число GPU-мешей в пределах 7–13;
спонсор по умолчанию выключен; ошибок JavaScript не зафиксировано.
Это ограниченная проверка ресурсов, а не доказательство отсутствия любых
утечек при многочасовой работе.

**Не проверено:** Xvfb не выставил `document.hidden` при переходе к другой
вкладке. Автоматическая пауза при реальном сворачивании реализована, но
успешной браузерной проверкой не считается. В JSON статус `not_checked`.

В первом финальном прогоне C5 desktop снимок превысил тайм-аут 30 секунд.
Повтор полного сценария отдельно прошёл; исходный неудачный запуск сохранён
в `desktop-first-attempt.json`, а итог C5 содержит `previous_attempt`.
Исправлена и ошибка самого touch-теста: touchEnd больше не отправляется
без активного касания. Записи видео изолированы от снимков регрессии;
пять затронутых desktop-сценариев дополнительно пройдены заново.

## Записи и визуальная проверка

Сохранены полные прохождения C1, H5, P5, S5, R5 в `artifacts/videos/`:
11.8, 15.6, 24.8, 23.8 и 6.0 секунды соответственно. Это видео реального
WebGL и обычного ввода, **без звука, 5 кадров/с с управляемыми часами**.
Это не запись работы на 60 FPS. Проверены стартовые и игровые кадры,
узкий экран, интерфейс и последовательные кадры из видео. Непрерывный
просмотр движения в реальном времени и прослушивание звука не заявляются.

Исправлены перекрытия подсказкой, размер счётчиков, активные вкладки,
доступность болтов и повторные нажатия, траектория отражения, защита соседней
конструкции, честный порог трёх звёзд C3. Реальные формы, тени, толпа,
поглощение, потоки, поворот пластин и каскад обломков отображаются в WebGL.
Физика разрушения плоская с трёхмерным отображением, не универсальный 3D-движок.

## Производительность — ограниченный реальный замер

C4, окно 1120×820, без подмены часов, только программный рендерер CPU:
- high: около **6.17 FPS**, медиана интервала 150 мс, p95 183.3 мс;
- low: около **9.44 FPS**, измерение в тех же условиях.

Полные интервалы, пиковые объекты и параметры — `artifacts/performance/results.json`.
Это короткая диагностика конкретного контейнера, не универсальный бенчмарк.
**60 FPS на пользовательской видеокарте и телефоне не подтверждены.**
Самые тяжёлые моменты всех пяти игр отдельным реальным FPS-прогоном не покрыты.
Режим экономии отключает тени и снижает разрешение без изменения правил.

## Остальные ограничения

Другой браузерный движок не запускался. Реальное HTTP-обновление страницы,
переход по ссылке и долговременное localStorage не проверены в этом браузере;
валидация URL, схема и повреждение сохранений/отказ хранилища покрыты unit-тестами.
Времена оптимального прохождения очень короткие — примерно 1–18 секунд самой
симуляции, без времени раздумья. Это не обещание 25–60 секунд каждого эпизода.
Человеческий плейтест, субъективная красота, звук на слух и долговременная
реиграбельность не доказаны автотестами. Материалы выполнены в едином
стилизованном игрушечном виде, не фотореалистичны.

## Воспроизведение

`npm test`; `npm run test:recipes`; `npm run build`.
Браузер: `python tests/browser.py --mode both`.
Регрессия: `python tests/regression.py`.
Записи (нужен FFmpeg): `python tests/record.py`.
Реальный диагностический FPS: `python tests/performance.py`.
На Linux без дисплея команды Python запускаются через `xvfb-run -a`.
Точные требования к среде — в README.
